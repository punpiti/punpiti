# Punpiti Piamsa-nga · พันธุ์ปิติ เปี่ยมสง่า

Associate Professor · Department of Computer Engineering, Faculty of Engineering, Kasetsart University

ผมทำงานด้านการประมวลผลภาพ ปัญญาประดิษฐ์ การวิเคราะห์ข้อมูล และการศึกษา ใช้พื้นที่นี้แบ่งปันโค้ดงานวิจัย สื่อการสอนแบบโต้ตอบ และเครื่องมือที่พัฒนาขึ้นสำหรับการทำงานจริง

[เว็บไซต์ส่วนตัว](https://madlab.cpe.ku.ac.th/punpiti/) · [Publications](https://madlab.cpe.ku.ac.th/punpiti/publications.html) · [บทความ](https://madlab.cpe.ku.ac.th/punpiti/articles.html) · [Apps](https://madlab.cpe.ku.ac.th/punpiti/apps.html)

## งานที่สนใจ

- Image Processing, Computer Vision และ Machine Learning
- Physics-Informed Machine Learning for Rainfall Nowcasting
- การใช้ AI ในการเรียนการสอนวิศวกรรมและการพัฒนาศักยภาพผู้เรียน
- Data Fusion for Public Policy and Trust Analysis
- ระบบสนับสนุนการตัดสินใจและการทำงานของมหาวิทยาลัย

## โครงการที่คัดมา

### เครื่องมือสำหรับทำงานกับ AI

- [Agent Project Kit](https://github.com/punpiti/agent-project-kit) — ชุดคำแนะนำและบันทึกสถานะโครงการ ช่วยให้ AI coding agents ทำงานต่อข้ามเซสชัน เลือกขั้นตอนให้เหมาะกับงาน และตรวจผลงานก่อนส่ง

### งานสอนและงานวิจัย

- [Machine Learning Demos](https://github.com/punpiti/machine-learning-demos) — สื่อสาธิตแบบโต้ตอบสำหรับเรียนรู้ Machine Learning เช่น backpropagation, autoencoder, random forest และ SVM
- [Dense-gauge Rainfall Diagnostics](https://github.com/punpiti/dense-gauge-rainfall-diagnostics) — โค้ดวิเคราะห์พัฒนาการของฝนจากเครือข่ายสถานีวัดฝนหนาแน่น พร้อมตัวอย่างข้อมูลสังเคราะห์
